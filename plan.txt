Let’s define a "window palette" to be the set of black / light grey / dark grey / white that is required to draw any window and widgets
Then let’s create several palettes:
- the standard one (as currently)
- a slightly green one -> used by menu and menu choice
- a slightly blue one -> used by dialogs
This way menus / dialogs / regular window will be directly identifiable by their color scheme.
Note: do not use any standard Java Color, instead define all Colors by their RGB directly.
